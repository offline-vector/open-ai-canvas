# Studio 浏览器图片存储

启用 `VITE_CANVAS_AUTH_MODE=guest` 或 `VITE_CANVAS_GENERATED_MEDIA_MODE=remote_only` 时，粘贴、选择及替换图片会把文件保存在当前浏览器 IndexedDB。画布和素材自动保存只同步结构与存储键，不触发图片文件上传。其他部署继续使用既有资源上传流程。

Blob URL 只对当前页面有效。刷新后，图片节点按 `storageKey` 从 IndexedDB 创建新地址，并供预览、裁剪、局部编辑和下载使用。浏览器数据清理或换设备后，本地文件不会从 Studio 服务器恢复；需要用户重新选择原图。

## 生成与参考图片

已有图片没有连接输入时，参考栏默认显示并使用当前图片；无需额外输入 `@图片1`。移除参考后按无图生成，再点击“使用当前图片作参考”可重新启用。已有连接输入优先使用连接的素材，避免把旧生成结果额外加入参考列表。

点击生成时，后端任务仍需读取参考图片：本地文件在此时通过资源接口提交；已有服务端资源直接使用资源 ID，HTTPS 图片直接使用远程地址。此策略仅取消添加图片和自动保存阶段的文件上传，不代表生成请求绕过 Studio 后端。

生成结果继续遵循 `remote_only`：保留上游媒体 URL，不新增 Studio 结果文件兜底。上游链接有效期和跨域策略仍由上游决定。

## 下载

创作页与画布先在浏览器读取媒体为 Blob，再保存文件，避免跨域链接导致当前页面离开工作区。HTTPS 链接不允许跨域读取或直接下载失败时，提供“新窗口打开原图”，用户可右键另存；当前工作区保留。不增加服务端下载代理。
